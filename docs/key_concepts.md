# المفاهيم الرئيسية لنظام تقييم BTEC

## نظرة عامة

نظام تقييم BTEC هو منصة تعليمية متطورة تستخدم الذكاء الاصطناعي وتقنية البلوكتشين لتوفير تقييمات موثوقة وشفافة لمهام الطلاب في برامج BTEC. يتميز النظام بواجهة مستخدم سهلة الاستخدام وآليات أمان متقدمة وقدرات متعددة اللغات.

## المكونات الرئيسية

### 1. نظام المصادقة والأمان

- **المصادقة المتعددة العوامل**: دعم للمصادقة الثنائية (2FA) باستخدام TOTP
- **تشفير**: تشفير قوي للبيانات الحساسة باستخدام مكتبة cryptography
- **توكنات JWT**: لإدارة جلسات المستخدمين بشكل آمن
- **تحديد معدل الطلبات**: حماية من هجمات الحرمان من الخدمة (DoS)
- **التحقق من IP**: تحليل وتسجيل عناوين IP للمستخدمين لكشف النشاط المشبوه

### 2. خدمات الذكاء الاصطناعي

- **AIEvaluator**: الخدمة الأساسية للتقييم الذكي
- **AIEvaluatorDirect**: خدمة مباشرة لا تتطلب سياق Flask
- **AIEvaluatorArabic**: متخصصة في تقييم المهام باللغة العربية
- **AIEvaluatorMultimodal**: تدعم تقييم النصوص والصور
- **AIEvaluatorAdvanced**: توفر تحليلات متقدمة
- **AIEvaluatorREST**: تستخدم REST API مباشرة (الأكثر استقرارًا)

### 3. خدمة البلوكتشين

- **توثيق التقييمات**: تخزين بصمة رقمية لكل تقييم على البلوكتشين
- **التحقق**: إمكانية التحقق من عدم تلاعب بالتقييمات
- **الشفافية**: توفير سجل دائم وغير قابل للتغيير للتقييمات

### 4. نماذج قاعدة البيانات

- **User**: لإدارة بيانات المستخدمين وصلاحياتهم
- **Evaluation**: لتخزين التقييمات ونتائجها
- **RubricTemplate**: لتخزين قوالب معايير التقييم
- **SystemMetrics**: لتتبع أداء النظام

## تدفق العمل الأساسي

1. **التسجيل والمصادقة**: يقوم المستخدم بالتسجيل وتسجيل الدخول
2. **تقديم المهمة**: يقوم الطالب بتقديم مهمته للتقييم
3. **التقييم الآلي**: يقوم النظام بتقييم المهمة باستخدام الذكاء الاصطناعي
4. **التوثيق**: يتم توثيق نتيجة التقييم على البلوكتشين
5. **العرض والتحقق**: يمكن للمستخدمين عرض التقييم والتحقق من صحته

## الواجهات

### واجهة المستخدم الرسومية (GUI)

تتوفر واجهة مستخدم سهلة الاستخدام عبر المتصفح، تدعم:
- ثنائية اللغة (العربية والإنجليزية)
- تصميم متجاوب يعمل على مختلف الأجهزة
- مخططات ورسوم بيانية للإحصائيات
- واجهة مسؤول متقدمة للمعلمين والإداريين

### واجهة برمجة التطبيقات (API)

توفر واجهة برمجة تطبيقات RESTful للتكامل مع الأنظمة الأخرى:
- تقييم المهام
- إدارة المستخدمين
- التحقق من صحة التقييمات
- الوصول إلى الإحصائيات

## الميزات المتقدمة

1. **دعم تعدد اللغات**: دعم كامل للغة العربية والإنجليزية
2. **تقييم متعدد الوسائط**: القدرة على تقييم النصوص والصور والمخططات
3. **معايير تقييم مخصصة**: إمكانية إنشاء وتعديل معايير التقييم
4. **المراجع والتدقيق**: نظام مُدقِّق (Mudaqqiq) للتدقيق الشامل
5. **لوحة تحكم تحليلية**: رؤى متعمقة حول أداء الطلاب والنظام
