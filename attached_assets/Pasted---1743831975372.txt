2. إعداد Render:

اذهب إلى Render.com وأنشئ حسابًا.

إنشاء قاعدة بيانات PostgreSQL:

انقر "New" -> "PostgreSQL".

اختر اسمًا، منطقة، وخطة (الخطة المجانية كافية للبدء).

انسخ "Internal Database URL" - هذا هو DATABASE_URL الذي ستستخدمه.

إنشاء خدمة ويب (Web Service):

انقر "New" -> "Web Service".

اربط مستودع Git الخاص بك (GitHub, GitLab, Bitbucket) الذي يحتوي على الكود.

الإعدادات:

Name: اسم لتطبيقك (مثل grok-castle).

Root Directory: اتركه فارغًا إذا كان Procfile في الجذر، أو حدد backend إذا كان داخله.

Environment: اختر Python 3 (تأكد من تطابق الإصدار مع بيئتك).

Region: اختر منطقة قريبة منك.

Branch: الفرع الذي تريد النشر منه (عادة main أو master).

Build Command: pip install -r requirements.txt (Render غالبًا ما يكتشف هذا تلقائيًا).

Start Command: gunicorn your_project_name.wsgi:application (يكتشفه من Procfile عادة).

Plan: اختر الخطة المجانية (Free).

الإعدادات المتقدمة (Advanced):

Environment Variables: انقر "Add Environment Variable".

أضف DATABASE_URL والصق القيمة التي نسختها من إعدادات قاعدة بيانات Render.

أضف DJANGO_SECRET_KEY وقيمة قوية جدًا.

أضف PYTHON_VERSION (مثل 3.11.5) لتحديد إصدار بايثون.

أضف WEB_CONCURRENCY (عدد عمال Gunicorn، ابدأ بـ 2 أو 3 للخطة المجانية).

أضف جميع متغيرات البيئة الأخرى المطلوبة (JWT_SECRET_KEY, ENCRYPTION_KEY, OPENAI_API_KEY, إلخ).

انقر "Create Web Service".

3. عملية النشر والترحيل:

سيبدأ Render تلقائيًا في سحب الكود، تثبيت التبعيات، وبناء التطبيق.

سيقوم بتشغيل أمر release من Procfile (أي python manage.py migrate) لتطبيق تغييرات قاعدة البيانات.

سيقوم بتشغيل أمر web من Procfile لبدء تشغيل Gunicorn.

سيستغرق هذا بضع دقائق في المرة الأولى. راقب سجلات النشر (Logs) لأي أخطاء.

4. الوصول وجمع الملاحظات:

بمجرد انتهاء النشر بنجاح، سيمنحك Render عنوان URL عامًا لتطبيقك (مثل https://grok-castle.onrender.com).

اختبر العنوان! تأكد من تحميل الواجهة الأمامية وأن وظائف API (مثل تسجيل الدخول) تعمل.

شارك الرابط مع المستخدمين التجريبيين.

استخدم آلية الملاحظات التي أضفتها لجمع آرائهم.
